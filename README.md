# 🧙 Jogo Mágico de Matemática Financeira

> Projeto de extensão universitária — Gamificação aplicada ao ensino de Porcentagem e Juros

---

## 📌 Sobre o Projeto

Projeto desenvolvido como atividade de extensão, com o objetivo de criar uma experiência de aprendizagem gamificada para o conteúdo de **Porcentagem e Juros** do Ensino Fundamental II e Médio.

A proposta usa a plataforma **Wordwall** para entregar um quiz de múltipla escolha com 15 questões, divididas em 3 níveis de dificuldade crescente, dentro de uma narrativa.

## 🎮 O Jogo

- **Plataforma:** Wordwall
- **Formato:** Quiz de múltipla escolha
- **Questões:** 15 (divididas em 3 blocos de 5)
- **Progressão:** Nível 1 → porcentagem básica / Nível 2 → juros simples / Nível 3 → juros compostos e análise financeira
- **Tema:** Magia & Fantasia
- **Custo:** Gratuito

> 🔗 Link do jogo: https://wordwall.net/pt/resource/114464700

## 📖 A Apostila

A apostila foi desenvolvida como **guia do professor** e cobre:

- Contexto narrativo e justificativa pedagógica
- Estrutura dos níveis e formato das questões
- 3 modelos de aplicação em sala (projetor, laboratório, extraclasse)
- Guia de uso do Wordwall
- Sugestões de avaliação diagnóstica e formativa
